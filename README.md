# Advanced Object Detection Lab (20 Marks)

YOLOv8 fine-tuning on the Ultralytics African Wildlife dataset.

## Dataset

- Name: African Wildlife (Ultralytics)
- Task: Object Detection
- Classes: `buffalo`, `elephant`, `rhino`, `zebra`
- Split: train / val / test
- Format: YOLO bounding box format
- Source: https://docs.ultralytics.com/datasets/detect/african-wildlife/

## Model

- Base model: `yolov8n.pt` (pretrained)
- Why pretrained (transfer learning):
  - Model already learned generic visual features on large datasets.
  - Fine-tuning reuses those features for wildlife classes.
  - Faster training and better results in limited lab time/CPU environment.

## Project File

- Main script: [african_wildlife_yolov8_lab.py](african_wildlife_yolov8_lab.py)

## Environment Setup

```bash
pip install ultralytics opencv-python matplotlib pyyaml
```

## Run Commands

### Standard lab run (CPU)

```bash
python african_wildlife_yolov8_lab.py --data data.yaml --epochs 5 --model yolov8n.pt --device cpu
```

### Faster demo run (if time is less)

```bash
python african_wildlife_yolov8_lab.py --data data.yaml --epochs 3 --imgsz 512 --batch 4 --model yolov8n.pt --device cpu
```

### Optional: display plot windows also

```bash
python african_wildlife_yolov8_lab.py --data data.yaml --epochs 5 --model yolov8n.pt --device cpu --show_plots
```

## Auto Dataset Handling

If `data.yaml` is missing, the script can:

1. Download the African Wildlife ZIP from Ultralytics.
2. Extract it in the workspace.
3. Create a valid `data.yaml` automatically.

## What the Script Produces

For each run, outputs are saved under:

- [runs/wildlife_lab](runs/wildlife_lab)
- Example run folder: [runs/wildlife_lab/yolov8n_finetune](runs/wildlife_lab/yolov8n_finetune)

Important output files in each run folder:

- `results.csv`: Epoch-wise training log (losses and metrics)
- `results.png`: YOLO training curves generated by Ultralytics
- `training_curves_preview.png`: Saved training-curve figure
- `test_detections.png`: Detection visualizations on test images
- `evaluation_metrics.txt`: Precision / Recall / mAP summary
- `evaluation_metrics.json`: Same metrics in JSON format
- `manual_iou_samples.json`: Manual IoU demo outputs
- `viva_analysis.txt`: Exam-oriented analysis notes
- `run_summary.md`: Run configuration + key results summary

## Evaluation Metrics Used

The script reports:

- Precision (mean)
- Recall (mean)
- mAP@0.50
- mAP@0.75
- mAP@0.50:0.95

IoU explanation for viva:

- YOLO uses IoU thresholds in mAP evaluation.
- Manual IoU formula:

$$
\text{IoU} = \frac{\text{Area of Intersection}}{\text{Area of Union}}
$$

## Viva-Oriented Performance Analysis

### 1. Dense Forest Background

- Many textures (leaves/branches/shadows) can create false positives.
- Precision may reduce due to confusion with background patterns.

### 2. Camouflage Conditions

- Low contrast between animal and background can hide boundaries.
- Recall may reduce due to missed detections (false negatives).

Short conclusion:

- Transfer learning with YOLOv8 gives strong baseline performance quickly.
- Dense clutter and camouflage remain challenging and affect precision/recall.
